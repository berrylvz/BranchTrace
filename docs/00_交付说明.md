# 枝迹（BranchTrace）MVP v1.0 — 完整设计包

**正式中文名称：枝迹**  
**英文名称：BranchTrace**  
**开发代号：`branchtrace`**  
**产品定位：树形项目管理 + 每日行动记录**

## 文件清单

1. `01_MVP_需求规格.md` — 已确定的产品边界、Project/Daily/回收站、状态与日期规则、交互方式、15 组验收测试。
2. `001_initial.sql` — SQLite 初始化迁移脚本（v1）；六张数据表、外键、约束和索引。
3. `03_Rust_API_设计.md` — Tauri Command 清单、请求/返回 DTO、rusqlite 专用工作线程、事务流程、Daily 聚合、错误码和缓存策略。
4. `04_品牌与工程命名规范.md` — “枝迹 / BranchTrace”命名、仓库和包名、Tauri 产品名/标识注意事项、SQLite 文件名和应用数据目录建议。

## 命名替换说明

- 产品原占位名称“Todo 软件”已统一替换为 **枝迹（BranchTrace）**；`Todo` 不再作为产品名。
- 原有功能视图仍称 `Project / Daily`，无需更改业务 API、SQL 表名或数据字段。
- 推荐 SQLite 文件名：`branchtrace.sqlite3`，但文件名不存于 SQL Schema，实际路径取决于 Tauri 应用标识与系统数据目录。
- 正式打包前必须选定稳定且可使用的 Tauri `identifier`；文档中的例子是占位符。

## 验证结果

- `001_initial.sql` 已在 SQLite 执行验证，建立六张数据表和对应索引，`PRAGMA user_version` 为 1。
- 校验外键完整性；重新打包时逐文件核对完整性。
- 命名调整仅修改文档文字与 SQL 注释，**未修改任何 SQL 表结构或业务约束**。

## 交付边界

- 本 ZIP 为**完整 MVP 需求、数据库和 API 设计包**，尚不是可运行桌面应用或安装程序。
- SQL CHECK 无法独自验证真实日期、终止日期与推进日期关系或防止项目循环，必须由 Rust 在事务中处理。
- 本地持久化不等于备份。第一版不包含自动备份、云同步、导入导出及桌面系统通知。
- 产品/商标/域名的使用权和正式发布标识需在发布前核查；本文件不承诺名称具备商标可用性。

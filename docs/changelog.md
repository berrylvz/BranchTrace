# Changelog

本文档记录 **BranchTrace** 各版本的核心功能、交互体验、接口契约与稳定性变化。

---

## v1.1.0（Calendar 视图统一与自定义时间段统计）

### 1. 主导航收敛为二视图（Projects / Calendar）

- 合并原重叠度较高的 `Weekly` 与 `Monthly` 两个一级导航为统一的 **`Calendar`** 视图，顶部导航精简为 **`Projects` / `Calendar`**（全局快捷键调整为 `1 / 2`）。
- 每次点击 `Calendar` 导航或按 `2` 均默认进入 **`Month`** 月历模式；在 `Calendar` 内可通过分段控件或 `M / S` 快捷键在 **`Month`** 与 **`Summary`**（自定义时间段统计）间切换。

### 2. 自定义时间段统计（Summary，最长 30 天）

- 取消传统固定周一至周日的只读七列 `Weekly` 视图，改为用户自由选择任意起止日期（含首尾 **1–30 天**）的 **`Summary`** 统计模式：
  - 提供起止日期选择器（超 30 天自动夹紧并提示）、快捷预设（`This Week`、`Last 7d`、`Last 14d`、`Last 30d`）以及按当前跨度平移（`← / →`）和跳转至今日结尾（`T` / `Latest`）；
  - 在 `Month` 月历中支持 `Shift + 点击` 两个日期快速框选统计区间，亦可在 `DayDetailPanel` 顶部一键汇总当周。
- 统计内容包含周期指标卡、自适应 1–30 天每日活动柱状图（点击柱子打开对应日期侧栏），以及 **`By Project`**（完成项目、带微型活跃格带的项目推进分布、含按时/提前/延后统计的可编辑提醒列表）与 **`By Day`**（可编辑按日时间线）双视角。
- 全局仅保留 `Calendar` 顶部一份共享的可编辑 `Overdue Reminders` 横幅，并移除 `DayDetailPanel` 在 Today 时的重复逾期区块。

### 3. 后端接口与测试

- Rust 后端新增 `get_daily_range(startDate, endDate)` Command 与 `DailyRangeDto`（严格校验起止顺序与 30 天上限，始终返回全局 `overdueReminders`），保留 `get_daily_week` 兼容现有项目时间线与测试；浏览器 Mock 与单元测试同步对齐。

## v1.1（相比 v1.0 初版的主要变化）

### 1. 视图架构重构：两视图升级为三视图（Projects / Weekly / Monthly）

初版包含 `Project` 与 `Daily` 两个主视图，其中独立提醒直接在 `Daily` 周视图中增删改查。v1.1 将主视图调整为三个职责更清晰的视图，并调整了提醒的管理入口：

- **Projects（项目视图）**：保留初版项目树的全部核心业务能力，并补充多项效率与交互改进（详见下文第 2 节）。
- **Weekly（周视图，原 Daily 视图改为只读）**：
  - 原 `Daily` 七列周视图更名为 **Weekly** 并调整为**仅可读（Read-only）**模式（工具栏标注 `Read-only`），用于集中回顾一周（周一至周日）的完成项目、推进项目及独立提醒。
  - 保留点击项目条目查看只读项目详情弹窗（`ProjectDetailModal`），新增“当天也推进过”标记（`Progressed same day`）。
  - 移除周视图中的新建提醒输入框、可点击复选框、拖拽排序手柄、行内重命名及操作菜单，避免在周回顾中误操作。
  - 支持从 Monthly 视图精准跳转至对应日期所在的自然周，自动高亮目标日期列（`Selected` 状态）并平滑滚动居中显示。
  - Grid 模式七列改为按内容自适应宽度（`computeWeekGridWeights`）：条目越多的日期列越宽（权重 0.7–1.6fr），今天与选中日期最低 1.2fr；空闲日期最小宽度降至 `150px`，使 1280px 窗口下一周七天无需横向滚动即可完整显示。
- **Monthly（新增月视图）**：
  - 新增完整自然月日历视图（按周一至周日排列的完整周网格，包含跨月首尾补齐日期），支持上一月 / 下一月 / 回到本月导航。
  - **点击某一天**：打开该日专属的提醒管理弹窗（`DayRemindersModal`），支持在该日内直接执行完整提醒操作——连续新建提醒（今天及未来日期，Enter 连续提交）、勾选完成/恢复、一键移入回收站、行内双击或 `F2` 重命名、修改计划日期、修改完成日期、取消/恢复以及同日拖拽排序。
  - **点击某一天区域中的 `Details` 按钮**（日历格右上角与该日弹窗顶部均提供）：直接切换到 Weekly 视图中对应的天，查看该日全部项目完成/推进记录与提醒明细。
  - **月历快捷交互与概览**：
    - 日历格内展示当日项目完成数与推进数徽章，以及该日提醒预览，并支持在日历格中直接勾选复选框快速完成或恢复提醒。
    - 顶部工具栏提供快捷新建提醒表单（标题 + 日期选择器），跨月新建时自动切换至目标月份。
    - 当存在未完成的逾期提醒时，在月历上方显示独立的 `Overdue Reminders` 面板，便于跨月直接完成或跳转定位，不因翻月而遗漏。

### 2. 项目视图（Projects）与交互体验增强

- **增大展开/折叠箭头可点击区域**：项目树节点展开/折叠按钮（`.tree-toggle`）视觉尺寸由 `18×26px` 增大至 `28×32px`，并通过伪元素将有效点击热区扩展至 `34×40px`，箭头图标增至 `16px`；同步将树形层级缩进调整为 `24px`（`TREE_INDENT`）以保持父子引导线对齐。
- **批量展开与折叠**：项目页标题旁新增 `Expand All` / `Collapse All`，在单个数据库事务中原子保存所有未软删除项目（含隐藏后代与终止态项目）的展开/折叠状态，不修改项目业务版本号。
- **行内编辑与树形移动体验**：
  - 新建子项目改为树内行内输入行（`InlineChildRow`），支持折叠父节点时临时展开、Enter 连续添加、Esc 退出且不覆盖持久化的折叠状态。
  - 重命名支持双击标题、`F2` 快捷键或菜单触发行内编辑，提交失败保留草稿并显示错误。
  - 跨级移动由原生下拉框升级为可视化树形选择器（`MoveProjectDialog`），自动排除自身及后代、缩进展示层级并用短 ID 区分重名路径。
  - 同级拖拽排序新增明确的前/后插入指示线；项目完成或取消后提供约 5 秒带版本校验的 `Undo` 撤销提示。
  - 已完成项目标题不再显示删除线（已由勾选图标、弱化文字色与 `Completed {日期}` 徽章表达），提升可读性；已取消项目保留删除线以便与已完成区分。
- **可访问弹窗、菜单与快捷键**：
  - 使用统一的自定义组件（`ActionMenu`、`Modal`、`FormDialog`、`ConfirmDialog`）与 SVG 图标集替代原生弹窗，支持项目行和提醒行的右键上下文菜单。
  - `Modal` 新增多层弹窗栈管理，确保在 `DayRemindersModal` 内打开 `ActionMenu`、重排期表单或删除确认框时，`Escape` 关闭层级、菜单 `z-index` 叠放及焦点恢复行为正确。
  - 全局快捷键更新为：`1 / 2 / 3` 切换 `Projects / Weekly / Monthly`，`N` 聚焦新建顶层项目，`← / →`（或 `[` / `]`）与 `T` 在 Weekly/Monthly 中翻页与回到本周/本月，`F2` 行内重命名。
  - 设置页新增带视觉预览的主题选择卡片（System / Light / Dark）与快捷键说明面板。

### 3. 全界面与提示信息英文化

- 应用界面中的所有文本全面改为英文，包括顶部品牌与导航（`BranchTrace`、`Projects`、`Weekly`、`Monthly`）、窗口标题与 HTML 语言声明（`index.html`、`src-tauri/tauri.conf.json`）、项目/周/月视图、回收站、设置页、弹窗表单、日期与周/月范围格式化（`src/ui-format.ts`）、无障碍标签（`aria-label` / `title`）以及通知提示。
- Rust 后端（`src-tauri/src/db.rs`、`src-tauri/src/lib.rs`）与前端浏览器 Mock（`src/api.ts`）的所有 `ApiError` 错误消息同步改为一致的英文表述。

### 4. 后端 API、数据安全与测试补强

- **新增 Tauri Commands 与 DTO**：
  - 新增 `get_month_calendar(month)` 命令及 `MonthCalendarDto` / `MonthDayDto`，在 Rust 单工作线程内批量查询并聚合整月网格、同日完成与推进去重后的项目计数、计划提醒、跨日完成提醒及全局逾期提醒。
  - 新增 `set_all_projects_expanded(isExpanded)` 命令，事务化批量更新 `project_ui_states`。
  - 沿用 v1.0 的 SQLite v1 Schema（`user_version = 1`），完全向后兼容初版数据库文件，无需迁移破坏。
- **数据库事务与异常韧性**：
  - 全部数据库写入操作统一使用 `BEGIN IMMEDIATE` 事务；应用关窗或退出时排空队列中的写入任务后再安全结束 DB 工作线程。
  - 数据库初始化失败不再 panic，改为渲染包含错误码与数据库路径的 `StartupErrorView` 保护已有数据文件；前端新增 `AppErrorBoundary` 兜底渲染异常。
  - 项目树排序与深层级硬删除改用迭代遍历并加入循环检测；跨午夜、窗口重新聚焦及页面恢复可见时自动同步本地时钟上下文并刷新相关查询缓存。
- **浏览器 Mock 对齐与回归测试**：
  - `src/api.ts` 中的浏览器离线 Mock 与 Rust 后端对齐全部业务校验、错误码、版本冲突保护、原子持久化与嵌套回收站批次隔离，并同步实现 `get_month_calendar` 与 `set_all_projects_expanded`。
  - 扩充自动化回归测试至 **17 项 Rust 测试**与 **30 项 Node.js 测试**，覆盖月视图聚合、日期/周计算、批量展开回滚与重启持久化、同级重排、嵌套回收站批次、版本冲突及错误恢复。
